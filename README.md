# Hakaton_TP

Программа читает письма из папки inbox, анализирует тему и текст письма, определяет категорию по набору ключевых слов и копирует письмо в соответствующую папку внутри processed.
Например, если в письме встречаются фразы срочно, ошибка 500, критический инцидент, письмо попадёт в категорию urgent.

Категории писем:
urgent - срочные и критические обращения;
respond_today - письма, на которые нужно ответить сегодня;
respond_soon - письма, требующие ответа в ближайшее время;
no_action — информационные письма без необходимости ответа;
spam — подозрительные или рекламные письма;
unknown — письма, которые не удалось классифицировать.


Инструкция по запуску:
Откройте терминал
Склонируйте репозиторий
git clone https://github.com/Kibala05/Hakaton_TP.git
cd Hakaton_TP

В терминале введите: 
bash run.sh

Перед использованием можно удалить предыдущие результаты и выполнить повторную обработку:
rm -rf processed
bash run.sh

Запуск тестов:
pytest tests/ -v


После запуска программа:
1. Прочитает все письма из папки inbox.
2. Определит категорию каждого письма.
3. Создаст папку processed, если её ещё нет.
4. Разложит письма по подпапкам (см. категории писем)
